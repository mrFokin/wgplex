# wgplex — мост для OpenCode

Источник правды проекта — `CLAUDE.md` этого репозитория. Прочитай его целиком до любых действий; OpenCode автоматически его не загружает, этот файл обеспечивает загрузку и разрешает пересечения экосистем.

## Приоритет правил
1. `CLAUDE.md` — проектная правда (структура, принципы, root и система, git, сессии, мультиагентный процесс). Он главнее там, где расходится с глобальным каноном.
2. Глобальный канон `~/.config/opencode/AGENTS.md` — универсальный процесс: роли (`agents/<роль>.md` каталога канона), брифы и план этапа (`procedures/orchestration.md`, `procedures/plan.md`), умения-скиллы (`wiki-ingest`, `wiki-query`, `wiki-lint`).

## Расхождения экосистем
- Коммиты: в сессиях OpenCode подпись `Co-Authored-By` не ставится (канон); у CLAUDE-сессий — как в CLAUDE.md.
- Роли: `.claude/agents/*.md` обслуживают Claude Code; в OpenCode роли — из каталога канона файлами.
- Языки коммитов: CLAUDE.md и канон совпадают (префикс англ., описание по-русски).

## Путеводитель по проектным документам
- `docs/design.md` — дизайн и план этапов (раздел 21).
- `docs/api.md` — публичный контракт API (на английском); по CLAUDE.md обязателен — в `docs/` его нет, следующим действиям нужно выяснить, где он живёт (см. репозиторий `wgplex-app`) или зафиксировать пробел.
- `docs/plans/m<N>-<slug>.md` — планы этапов; ход работы и результаты отмечаются в них.
